# @brewdocs/core

Core extraction pipeline for BrewDocs: README / package.json / JSDoc-TSDoc /
exported-symbol extractors, markdown + syntax highlighting, themes, search
index, versioning, and deploy/storage adapters.

Part of BrewDocs — brew your docs, serve them hot.

`Source -> ExtractResult -> RenderModel -> standalone HTML`

See the main repo for docs and usage: https://github.com/coffeetocoffee/brewdocs
